# 🐔 Smart Poultry Management System

A modern full-stack Smart Poultry Management System designed to help poultry farmers manage farms, flocks, eggs, feed, health records, finance, weather monitoring, and user management from a single platform.

## 🚀 Features

- Multi-Farm Management
- Role-Based Authentication (JWT)
- GPS-Based Farm Location
- Weather Monitoring
- Chicken & Flock Management
- Egg Production Tracking
- Feed Management
- Health Records
- Financial Reports
- Responsive Dashboard

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (ES6)
- Vite

### Backend
- Spring Boot
- Java 21
- MySQL
- JWT Authentication
- Flyway
